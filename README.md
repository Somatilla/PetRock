# PetRock
I’m making a game where you have your own pet rock.
If your rock goes hungry, there’s a button with a blue crystal on it to feed him (the yellow progress bar shows hunger)
Also, there is happiness in the game too! Give your rock a head-pat to make it happy!

More will be added later!

I used ChatGPT for debugging and a bit of coding :/
